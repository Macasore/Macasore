# 💫 About Me:
I'm a backend software engineer and co-founder of Reedapt, an AI-powered dubbing and live interpretation platform built for African languages. I design and run the production ML infrastructure behind it, GPU pipelines on AWS ECS, diarization and voice cloning models, and the systems that keep them fast and reliable at scale. My background spans fintech backend engineering (Python, Java/Spring Boot, payment rail integrations) and applied AI systems
